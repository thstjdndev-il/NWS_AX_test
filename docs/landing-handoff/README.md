# 바이브코딩 캠프 랜딩 · 개발 전달 명세

NWS 바이브코딩 캠프 홍보 랜딩 페이지(데스크톱)의 디자인·인터랙션 명세예요.
**동작하는 프로토타입이 정답**이고, 이 문서는 그 프로토타입을 실제 서비스로 옮길 때 필요한 값과 규칙을 정리한 거예요.

> 카피와 이미지는 **더미**예요. 기획 쪽에서 정리한 최종 문구·이미지로 교체될 예정이니, 텍스트와 이미지는 바꿔 끼울 수 있게 만들어 주세요.

### 프로토타입 열기

갤러리가 WebGL로 이미지를 그려서, 파일을 더블클릭하면(`file://`) 갤러리가 안 보여요. 폴더에서 로컬 서버를 띄워 주세요.

```bash
cd prototype
```

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 열면 돼요.

### 1-3. 타이포

- 폰트: **Pretendard Variable** 공식 웹폰트 (동적 서브셋 사용 권장). 프로토타입은 페이지에 쓰인 글자만 담은 폰트를 직접 넣어 둔 상태라 **실제 구현에 그대로 쓰면 안 돼요.**
- 섹션 헤더: 소제목 15 SemiBold Deep Blue → 제목 40 Bold Indigo (줄 높이 130%, 자간 -2%) → 설명 17 Regular Gray700 (줄 높이 165%). 간격 24px (07·08·10은 16px)
- 한국어 줄바꿈: `word-break: keep-all`

### 1-4. 레이아웃·반응형

- 디자인 기준 폭 **1440px**. 섹션 내용 폭 1160px(좌우 140px), 03 Showcase만 1360px(좌우 40px)
- 섹션 위아래 여백 112px. 헤더 → 본문 간격은 섹션마다 다름(아래 각 섹션 참고)
- **601~1439px**: 1440 레이아웃을 그대로 두고 화면 폭에 맞춰 비율 축소 (프로토타입은 `zoom: 화면폭 / 1440`). 카드 열 개수는 바뀌지 않아요
- **600px 이하(모바일)**: 이번 범위 밖. 모바일 시안은 Hero(M01~M03)만 있어요

### 1-5. 공통 인터랙션 규칙

| 규칙 | 값 |
|---|---|
| 섹션 요소 등장 | 화면에 15% 보이면 `translateY(28px)→0`, `opacity 0→1`, 0.7s `cubic-bezier(.22,1,.36,1)`. 형제 요소끼리 80ms 간격 |
| 숫자 카운트 | 0.6~0.9s, ease-out. 가격은 천 원 단위로 올라감 |
| 동작 줄이기 | `prefers-reduced-motion: reduce`면 모든 애니메이션 없이 최종 상태 표시 |
| 화면 밖 | 화면 밖이거나 탭이 숨겨지면 WebGL 애니메이션 정지 |
| 앵커 이동 | 메뉴 클릭 시 부드러운 스크롤, 헤더 높이만큼 여백(`scroll-margin-top: 80px`) |

### 01 Hero

별도 명세 **`../hero-interaction/README.md`** 를 따라 주세요. 요약만 적으면:
- 페이지 진입 시 **한 번만**: 프롬프트 타이핑 → 가짜 커서가 Send 클릭 → 프롬프트 축소 + 렌즈 갤러리 펼침(3s, `cubic-bezier(0.12, 0.9, 0.25, 1)`) + 카피 상승
